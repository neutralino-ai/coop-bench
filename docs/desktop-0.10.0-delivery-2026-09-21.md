## 功能

- 注册 token 仅供一次注册；已有账号继续用用户名、密码登录。
- 大厅“我创建的”“我参与的”由服务器账号归属提供；创建者不必入席即可管理房间。
- 返回大厅保留人类原席位，重新登录/换设备可恢复。开局前另设明确的释放席位。
- 管理房间同时要求创建者会话和独立房主 token，由原生层自动恢复；开局后可复制原 seat token，强制结束需要确认。
- Agent 状态区分请求模型、等待、重连、失败、停止。恢复继续原席位、本设备上下文和待确认动作。
- 回放和输入审计分开，实际模型请求、服务器签发观察和模型实际返回的 reasoning 各有来源，不补造隐藏思考。

## 发布与验证

正式发布由 [四平台流水线 35602174531](https://github.com/neutralino-ai/coop-bench/actions/runs/35602174531) 统一执行。Release 必须包含 Windows、Mac Intel、Mac Apple Silicon 的管理端/Player 安装器及压缩包、同版本 iOS Xcode 工程包和 SHA256SUMS。iOS 未通过时发布任务不能执行。

候选已通过 98 项客户端测试、Windows 本机管理端 110 项/Player 25 项验收以及四平台 CI。iOS 包含 3 项原生单元测试、44 项模拟器流程和未签名真机 Release 编译。合成流程检验客户端行为，不是模型能力或胜率证据。

iOS 沿用自己的 Mac / Xcode 自签安装，[安装步骤](../ios/README.md)。Xcode 工程包不等于签名 IPA、TestFlight 或实体 iPhone 安装验证。内置 Agent 需要客户端持续运行；iOS 需保持前台。模型上下文和 API key 不随账号跨设备同步。

原有账号/密码保留。旧席位首次需原 seat token 绑定账号；旧记录如果只有不可逆摘要，复制接口不会擅自轮换凭证。服务端保留旧对局、动作、原始消息与附件，中止不冒充正常胜负。
