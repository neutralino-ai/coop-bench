# Coop Bench 0.11.4

Agent 完整轨迹改为紧凑卡片：User/System 蓝色、Assistant 紫色、Thinking 黄色、Tool use 橙色、Tool result 绿色。默认显示一至两行必要内容，类型、时间和详情入口共用一行；展开查看完整原文、参数和回执。重复的服务器确认与能够准确关联的工具回执合并展示，原始证据保留。

本轮动作的 tool use 优先显示并高亮，按原始观察编号或当前行动窗口关联。切换历史步骤会更新高亮，不用相似动作或时间近似匹配。模型请求配置与工具定义移入输入卡详情，减少重复块。

一并包含此前未正式发布的修复：iPhone 房主开局后 HTTP400（消息分页500改为100）；进行中回放高亮当前待行动玩家、同步服务端倒计时；历史和已结束对局高亮所选行动者；菜单连接灯可点击强制检查，底部单行可拖动数字时间条；扩大完整轨迹和行动理由空间，1280×800下轨迹区约391px。

支持服务端 default-action-v2 超时策略：花火可弃牌时弃第一张，否则出第一张。既有对局沿用已存策略和期限。断网结果不明仍用原请求编号确认，成功以服务端回执为准。

桌面三平台与 iOS 统一版本，macOS 签名、公证，iOS 通过 TestFlight 分发。模拟器及签名发布不等于实体设备验收。
