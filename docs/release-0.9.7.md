# Coop Bench 0.9.7

人类参赛页将原“我的动作”区域改为醒目的回合状态与大号倒计时：轮到自己显示“轮到你了”，队友回合显示玩家名字和“行动中”。倒计时沿用服务器期限和时钟校正；结束后隐藏，超时显示等待服务器更新。

- 移除花火页的“更多操作”折叠表单，直接点牌选择出 / 弃 / 颜色 / 数字并确认。
- 移除人类参赛页的“完整本席观察”、原始局面 JSON 和轨迹上传统计，保留可读的动作历史及牌主提示知识。记录与上传仍照常进行，管理端审计入口保持可用。
- 其他游戏必需的动作表单直接展开，无须点击三角形。

本版本仅修改客户端页面，不更改游戏规则、账号、房主权限或后端部署。配套输入审计的后端启用状态独立于本次发布。三平台安装包通过合成 API 包内验收及内容边界检查后发布；不等同于实际 Mac 手工安装或模型实局验证。
