# Coop Bench 0.11.14

- 时序迷局（Take Time）现在可从服务端目录选择全部 40 个主线时钟（I-1 至 X-4），并设置重试奖励及六种可选的 Rebirth 规则。选关由房主操作；本版尚不记录账号的自动闯关进度。
- 桌面和 iOS 的房间创建、玩家牌桌及回放提供六区时钟、当前指针与行动者、可见牌背、手牌、阶段规则、计时和终局条件。人类玩家可预览并确认合法动作；内置 Agent 沿用行动理由、真实模型消息和轨迹审查。
- 后端仍负责规则、合法动作、信息可见性、计分和历史回放。较早的 I-1 对局继续使用原规则版本，客户端不会用后来揭示的信息填补早期回放。

新关卡依赖 34936 服务端同步更新。客户端与 iOS 工程统一为 0.11.14；签名安装包、TestFlight 和公开下载以本版发布工作流的结果为准。
