# Sky Team：YUL 官方基础关实现

核验日期：2026-09-16。入口：`src/games/sky-team.ts` 导出 `skyTeam`。场景 ID：`yul`。固定两人，`p1` 是蓝色飞行员，`p2` 是橙色副飞行员。

## 资料完整性与实现范围

依据出版商 Le Scorpion Masqué 公开的 [Landing Procedure，2023-06-06 英文版](https://www.scorpionmasque.com/sites/scorpionmasque.com/files/st_rules01_en_06jun2023.pdf)，并用较新的 [2023-11-08 法文版](https://www.scorpionmasque.com/sites/scorpionmasque.com/files/st_rules01_fr_08nov2023.pdf) 交叉核对。PDF 正文和图面均已检查，而非仅从搜索摘要转录。

基础 YUL 场景所需全部数值部件均出现在官方规则书中，不缺关键卡牌，因此保留并实现。这里只代表蒙特利尔教学飞行，不代表全套 21 个场景、Flight Log 模块或 Turbulence 扩展。未将其他机场、燃料、实习生、风、冰刹车、额外能力等省略后冒充完整游戏。

## 与统一接口的对应

```text
setup(yul, 2, seed)
  → discussion：双方观察公共面板、message、ready
  → 双方 ready：一次生成各自四颗私有骰子
  → placement：轮流 place；不能 message
      ↘ 任一方 request_reroll
        → reroll：两人独立 reroll_selection，可传空列表
        → 双方提交后固定次序重掷，恢复原放骰轮次
  → 八颗放完：检查强制动作，下降高度
  → 下轮 discussion，或官方成功/失败结果
```

`observe` 只给自己剩余骰子、双方剩余数量、公共面板和允许公开的记录。所有 RNG 状态、对方骰子以及对方重掷选择均不会出现于自己的观察。讨论阶段本轮骰子尚未生成。

`legalActions` 给动作 JSON Schema 和当前可执行示例。放骰示例枚举所有合法的骰子、格子、最终值与咖啡花费组合；合法动作可能导致失败，规则内核不代替玩家避免撞机或遗漏强制动作。调用失败不会改变输入状态。

### 动作实例

```json
{"type":"message","text":"这一轮优先清理前方交通。"}
{"type":"ready"}
{"type":"place","dieId":"p1-d1","space":"engine-p1","value":4,"coffee":0}
{"type":"request_reroll"}
{"type":"reroll_selection","dieIds":["p1-d2","p1-d4"]}
```

任意玩家都可在放骰动作边界使用重掷，而不只限于当前玩家。因此有重掷标记时 `activePlayers` 包含两人，但非当前玩家只有 `request_reroll`，没有 `place`。调度器应查看每位玩家实际动作列表。

自由讨论保留官方的表达自由，不强制说满若干句话。两人提交 `ready` 是数字化结束讨论的握手机制，不是额外回合或必说内容。官方禁止谈论骰子及其条件策略，程序强制讨论时段，内容语义与暗号约定仍需审计；机械获胜结果不代表通过了沟通内容合规审计。不存在完美的自然语言自动裁判。为此 `metadata.implementation.verifier` 明确为 `objective-only`：机器精确判断动作与降落结果，但不声称已证明自然语言沟通合规；RLVR 标签也应保留这个边界。

## 重要裁定

- 进入含交通的当前位置不会立刻输；带着交通继续向前，或两格移动中穿过交通，才撞机。
- 先到机场允许滞空，但再向前会越过机场。降至 0 高度仍未到机场直接输；不能靠最后一轮引擎补距离。
- 最后一轮引擎只比较刹车。比较结果在第二颗引擎骰落下时锁定，此后展开刹车不能补救此前条件。
- 红标记在刻度之间。展开第一档后，两颗 1（和为 2）能满足低于 2.5 的条件。
- 已展开开关可再次放满足条件的骰子但不再推进标记；序列限制针对展开顺序。依据第 4 页“无骰即空格”的通则及第 7 页已亮灯无额外效果的说明。
- 重掷选择提交次序不改变随机数的归属。双方各自选好后，以固定玩家/骰子顺序生成新值。

## 验证

运行 `node --test test/sky-team.test.ts`，16 项通过：包含确定性、隐藏信息不变性、拒绝不变性、语音阶段、咖啡、开关次序、轴、交通、机场、重掷、强制动作和刹车时机。另以 40 个种子跑合法动作至终局，验证无状态机死路；这不是策略胜率实验。降落成功/失败边界测试使用明确标注的测试局面，不宣称是智能体真实获胜轨迹。
