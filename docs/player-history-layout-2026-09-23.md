# Player 席位顺序与动作历史调整

用户反馈：三人局的三号玩家被排到第一排；理由和语音占据主要空间；本轮队友动作被折叠，且长句难以阅读。

## 修改

- 删除手机样式中 `.own-hand` 优先排序，按席号数值排序所有手牌；标题显示席号、姓名及“我”。三号玩家固定在第三排，自己的牌面继续隐藏。
- 删除人类玩家理由表单、提交关联、iOS 听写桥接、原生识别实现及麦克风/语音用途声明。模型运行器的决策摘要和原有审计记录不改动。
- 牌桌上方增加始终展开的“本轮动作”，按发生顺序显示最近一次本人可见行动之后的队友动作。本人首次行动前显示开局以来的动作；接受本人行动后的新观察到达时清空本轮，随后继续追加队友动作。
- 全部动作历史默认展开，最新在前。提示、出牌和弃牌均显示为单行，包含席号、动作、提示值或公开牌面，失败明确标红。点一行可以查看完整姓名、命中牌位和时间。
- 历史继续只取本席 `visibleHistory`，不访问审计接口、不消费 Agent 的待处理观察。分页完成即使没有更换 observationId，也会更新同步提示。
