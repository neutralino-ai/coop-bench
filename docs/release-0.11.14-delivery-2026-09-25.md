# Coop Bench 0.11.14 delivery (2026-09-25)

The user reported that 0.11.13 still exposed only Take Time I-1 and requested a new version. The merged private backend implementation and public client implementation were already present, but 34936 still ran the old catalog. The private service was separately deployed and the live unauthenticated `/api/v1/games` now returns 40 Take Time scenarios, from `official-clock-1-1` to `official-clock-10-4`, plus the clock setup schema. Its health build is `16a6309d4a2ba61e2e3eab71aa45ef31fd574239afce34f0ca41bbddcadc0e12`. The previous 34936 runtime, database backup and old 34935 service were retained; the private server repository has the detailed audit.

Client PR [#3](https://github.com/neutralino-ai/coop-bench/pull/3) merged to public `main` as `0629c6a04c408cd4e692b249b8afce3dfe794ce3`; tag `v0.11.14` points to that commit. It bumps desktop and iOS together and documents selectable clocks, Rebirth options, the human/model board, reasons and replay. The PR also made the iOS synthetic-history assertion read one synchronous render snapshot: the first simulator run failed while reading a fixture across separate asynchronous calls; the corrected PR CI passed both iOS workflows, Windows, Intel/Apple Silicon Mac and quality checks. Local repository policy, ESLint, strict TypeScript, all 132 unit tests and desktop/shared iOS builds also passed.

The [signed tag workflow](https://github.com/neutralino-ai/coop-bench/actions/runs/36082603414) completed successfully: Windows x64, macOS Intel and Apple Silicon management/Player packages, iOS simulator acceptance, signed iOS IPA export, Mac signing/notarization/stapling checks, TestFlight upload and publication. The signed iOS evidence records bundle `org.coopbench.ios`, version `0.11.14`, build `44.1`. The [public Release](https://github.com/neutralino-ai/coop-bench/releases/tag/v0.11.14) is not a draft or prerelease and has all 12 expected uploaded assets, including checksums and the same-version Xcode project. [Public download verification](https://github.com/neutralino-ai/coop-bench/actions/runs/36084037454) succeeded by discovering the new version with the older updater, downloading the Windows installer and iOS project without credentials, and checking sizes and SHA-256 against the Release metadata.

Apple accepted the IPA upload, but this record does not equate upload with processing, internal/external TestFlight availability or a physical-device playthrough. The existing external group's 0.11.13 build was still marked Waiting for Review when inspected; the new 0.11.14 group and Apple processing state require a fresh App Store Connect check. Automatic account campaign progression is not implemented: the room host selects any of the 40 clocks explicitly.
