# 非 RPG 沟通合作桌游：卡牌组补充研究

核查日期：2026-09-16。候选选择以“全员共同结果、隐藏信息与沟通协作、无角色养成”为主。BGG 总榜是近期搜索索引快照，不是实时接口；排名与研究优先级分开。本文是选型研究，不表示已实现环境。

## 1. The Crew: The Quest for Planet Nine

这是合作吃墩游戏：每个人仍有自己的任务，但胜利归全队；没有角色成长。玩家以有限的通信标记展示一张牌及其在同色牌中的关系，并从出牌与任务选择推断队友手牌。人数通常为 3–5；2 人规则有人工队友安排，不能简单少发一份牌代替。

- [官方英文规则，22 页](https://www.thamesandkosmos.com/manuals/full/691868_Crew_Manual.pdf)：牌组、跟色、王牌、任务、通信、2 人变体可查。
- [法国发行商 IELLO 官方产品与下载页](https://iello.fr/jeux/the-crew/)：明确 50 任务；分别列出规则、Journal de bord、Deimos 和 ISS 额外任务下载。
- [Thames & Kosmos 官方 Deimos 额外任务入口](https://corporate.thamesandkosmos.com/index.php/educators/scienceathome/category/the-crew-the-deimos-adventures)：列出五份 Print-and-Play 条目；本次第一份详情页面获取失败，不能声称五份正文均已逐项核验。
- [德国官方规则与日志页](https://fragkosmos.zendesk.com/hc/de/articles/8069483104412-Die-Crew-Reist-gemeinsam-zum-9-Planeten-Anleitung-Logbuch-DE-Art-Nr-691868)：本轮未确认该入口提供完整 50 任务正文，不能仅凭 Logbuch 文件名认定全部任务已经取得；完整性以实际逐页内容核验为准。

**资料边界：**英文 22 页规则 PDF 不包含完整 50 关正文；完整任务导入应继续核验 IELLO 日志下载内容。官方产品说明有 50 关与公开规则，是不同证据。

**RLVR 判断：**很适合。跟色、墩归属、任务先后与胜负能由程序精确判定。通信必须是规则允许的结构化动作；把任意聊天接上会破坏信息限制。训练划分需按任务规则与牌局种子，区分同任务新发牌和真正新任务。基础版与 Deep Sea 可以复用吃墩内核，任务判定器应独立。

## 2. The Gang

合作版德州扑克排序：每人有私有手牌，共同牌逐步揭开，玩家通过领取或交换排名筹码表达自己相对强弱，最终全队正确排序才算该次成功。这里没有玩家间争夺底池。

- [Kosmos 官方产品页](https://www.kosmos.de/products/the-gang)：说明同时操作、禁止交换手牌信息及挑战/专家卡。
- [官方英文规则 PDF](https://www.thamesandkosmos.com/manuals/full/683887_TheGang_Manual-Web_051624.pdf)：3–6 人，先开三座金库或先触发三次警报；基础游戏不使用挑战与专家卡。
- [发行商规则索引](https://support.thamesandkosmos.com/hc/en-us/articles/360046967034-Product-Instruction-Manuals-Downloadable-PDFs)：分别列出基础、Deluxe 与 7–10 人扩展，不能混用人数。

**资料边界：**基础规则和普通 52 张牌足以定义初期数字环境；进阶模式需逐张核验挑战/专家卡。当前 PDF 直开重定向报错，搜索索引仍返回规则正文，因此卡面全集尚不应标记“已读取”。

**RLVR 判断：**很适合，扑克手型比较与成功次数都能精确验算。要特别测试平局、从 7 张中选最佳 5 张、A 的高低顺子、筹码被交换后的确认失效、同时操作及每阶段完成条件。不能为方便 API 擅自把自由同时调筹码改成固定一人一步且不可回改。此同步设计比扑克评分函数更容易改变游戏本身。

## 3. Hanabi／花火

自己看不到自己的牌，却能看到队友的牌；消耗有限提示资源，帮助全队按颜色与数字搭出烟花。无角色成长。它同时适合“能否推断队友意图”和“新队友能否理解已有约定”的研究。

- [Cocktail Games 官方法文基础规则，2019](https://www.cocktailgames.com/wp-content/uploads/2016/03/Hanabi_regles_0519_BD.pdf)：50 张基础牌、2–5 人、提示/弃牌/出牌、0–25 共同计分、三次错误失败。
- [R&R Games 官方英文规则](https://www.rnrgames.com/Content/RRGames/images/ProductRules/hanabiRules.PDF)：可访问，但主要为扫描图像，本次未以机器文本充分读取。
- [官方发行商下载索引](https://www.cocktailgames.com/telechargements/)：将基础 Hanabi 与 Hanabi grands feux 分开。

**结果必须保真：**基础 Hanabi 是合作得分游戏，有满分完成和爆炸失败。不要任意定义“20 分就是官方胜利”。法文规则另有完美烟花才算赢的专家变体，连终局条件也不同，不能只改奖励阈值冒充该变体。

**版本差异必须锁定：**2019 法文规则明确给出“没有某颜色/某数值”的空提示示例；常见美版 Deluxe 文本另有禁止零张提示的规定。后续实现须固定具体版次，对空提示、满提示能否弃牌、最后一轮及花色扩展逐项核验，不能把网上实现当成唯一官方规则。

**RLVR 判断：**很适合共同计分和成功率评测；正式对局用结构化提示，赛前协议学习可单独研究。合法动作列表本身不得泄漏玩家看不到的手牌；例如不能只列出“实际能成功打出”的自手牌。SFT 应保留当时可见提示及动作，不能把事后完整手牌写回决策输入。

## 4. The Mind

- [Pandasaurus 官方产品页](https://pandasaurusgames.com/products/the-mind)：2–4 人，沉默合作、递增出牌、等级递进。
- 官方产品页所链接的英文规则目前跳转 Dropbox 登录；[NSV 原版英文规则地址](https://nsv.de/wp-content/uploads/2018/05/TheMind_GB.pdf)本次也未成功获取。因此本次只确认官方规则入口与产品机制，完整规则版本仍待锁定。

它与 Take Time 相近，但共享时间感、等待多久、何时抢先出牌是游戏的重要部分。轮流调 API 并等待每位模型生成结束，会把模型服务延迟变成规则信号；直接让一号、二号、三号轮流出牌则改变了游戏。

**RLVR 判断：**结果可以验证，交互保真较难。应另设实时模拟协议，或明确标记离散时间研究改编。不能让 agent 读取真实牌号对应的推荐等待时间；公平性需要统一模拟时钟与延迟策略。它不适合最先实现的纯回合制基准。

## 5. The Game

- [Pandasaurus 官方产品页](https://pandasaurusgames.com/products/the-game-kwanchai-moriya-edition?c=evergreens)：1–5 人，共同向两堆递增、两堆递减的牌堆出牌；不能透露具体手牌信息。
- [从官方产品页链接的英文规则](https://www.dropbox.com/scl/fi/rux1sfbevshr8x593n0a2/P_TG_Rulebook_Print.pdf?dl=0&rlkey=6bbw1wlsych1lrxznas12g6ty&st=sn56zvzr)：本次浏览只取到 Dropbox 页面，未充分读取 PDF 正文。
- [NSV 英文规则地址](https://www.nsv.de/wp-content/uploads/2024/04/TheGame_GB.pdf)：本次 403，标记为待进一步获取。

**RLVR 判断：**数字排序与合法逆行规则容易精确验证；自然语言交流是否暗示具体数字较难自动判断。应区分“官方允许范围内的自由语言实验”与“限定消息模板研究版本”。发牌数量、每回合最低出牌量、牌库耗尽后的变化、允许交流边界需先锁版；产品营销简介不能代替规则正文。

## 6. Regicide：边界备选

- [官方玩法入口](https://www.regicidegame.com/how-to-play/)
- [官方规则全文，两页](https://www.regicidegame.com/site_files/33132/upload_files/RegicideRulesA4.pdf?dl=1)
- [官方产品与系列说明](https://www.regicidegame.com/)

基础版是 1–4 人普通扑克牌合作资源管理，没有角色数值成长或跨局剧情解锁；但题材是逐个击败 12 个敌人，与本轮希望淡化的打 Boss 体验接近，因此只放边界备选。**Regicide Legacy** 明确加入连续任务、奖励与牌组变化，应排除。

**资料/环境可行性：**基础版两页官方规则已经包含扑克值与花色效果、敌人生命/攻击、通用组合、免疫、Jester、单人变化；适合精确胜负验证和随机局生成。基础版没有官方编号关卡列表，不能把每张敌人当成独立官方关卡。

**沟通/bug：**平时禁止透露或暗示私有手牌；Jester 后只暂时允许表达是否愿意下一步行动。应测试红桃补牌与方块抽牌的先后、免疫解除的追溯范围、恰好击败回牌堆、击败后由同一玩家继续、连续 yield 限制、弃牌承伤。胜负是全队统一结果。

## 跨游戏结论

1. 核心优先覆盖 Planet Nine、The Gang、Hanabi，它们提供不同的隐藏信息结构；Take Time 和 Deep Sea 由主报告汇总。
2. “不能说话”仍然存在合法的行动信息渠道：出牌、取筹码、提示标记与行动时机。统一接口不能删除这些渠道，也不能额外开放聊天泄漏。
3. 结果字段应区分 `team_win_loss` 与 `team_score`；共同计分也是真正合作，不能为了统一奖励改写官方终局。
4. `ruleset_id` 应包含版次、玩家数变体和沟通模式。随机发牌、官方任务、研究生成任务分别登记。
5. 本文只提供规则理解与公开资料定位；公开下载本身不等于美术、完整规则文本或训练语料获再分发许可。
