# Coop Bench 0.10.1

- “我创建的”只显示未结束房间，管理按钮放在右侧。房间页保留入席设置、开始、踢人和强制结束，审查入口移到回放。
- 进行中对局支持实时回放；翻看历史时保留所在步骤，停在末尾时跟随最新进展。
- 人类可选填行动理由，确认动作时一起提交；iOS 支持中文语音转文字，先采用并编辑草稿再提交。
- 内置 Agent 必须提交中文理由；遗漏或只写英文会收到修正要求。HTTP 字段 `decisionSummary` 对人类仍为可选，不传给队友。
- 回放以不同颜色的滚动卡片展示系统提示、模型输入、实际返回的推理/回复、工具调用及结果，最新在上，提交理由高亮。大请求分片校验后重组，可继续分页读取完整轨迹。

旧局没有记录的理由或模型未返回的内部思考无法补造。iOS 附同版本 Xcode 工程供 Mac 自签安装，不是已签名 IPA；模拟器检查不等于真机麦克风验收。
