# 公开客户端与私有后端的边界

2026-09-20 用户要求后端独立私有、公开前端不保留后端历史。

采用新仓库身份而非只删除当前文件：原完整仓库转为私有并迁名；本仓库以全新的根提交建立，保留原客户端地址，避免更新器更换目标。旧提交、tags、Releases 和 Actions 资产不导入。

0.9.0 及更早的公开安装包曾包含可选单机游戏后端。它们已随历史仓库转私有；本仓库只发布 0.9.1 起的纯远程客户端。已经被第三方下载、缓存或克隆的副本无法由这次迁移收回。

允许公开：UI、客户端 HTTP/MCP 协议包装、模型运行器、请求/响应格式、公开规则来源、模拟客户端测试。

不公开：游戏裁决实现、权威状态/数据库实现、服务器启动与部署、云运维配置、真实实验轨迹、凭证、旧 Git 对象及含后端 bundle 的旧发布包。

客户端的本地 SQLite 仅用于请求日志/outbox/恢复，不是游戏权威数据库。包构建必须使用显式白名单，并拒绝 server.mjs、local-main.mjs、部署文件和游戏核。公开代码不能含到私有库的构建依赖；公开 CI 不使用私有仓库访问令牌。

旧开发 checkout 请另行保留或重新克隆。不要 pull 合并不相关历史，不要推旧 tags。代码私有并不能替代服务器权限检查、补丁、限流与凭据安全。
