# Coop Bench 0.9.2

- 打开应用首先显示简洁的密码登录页；登录后直接进入游戏大厅。
- 大厅并列显示可加入的房间和对局回放，进行中的游戏也可回放（遵守账号权限）。
- 顶部“创建新房间”支持房间名称、游戏、场景、人数和行动时限。
- 房主逐席发放 seat token，玩家点击房间并输入姓名、密钥后入席。自行生成或其他房间的密钥不能入席。
- 房间页实时显示成员。人类入席后自动准备，人齐且连接就绪时“开始游戏”可点击；等待状态保持普通鼠标指针。
- 支持离席、恢复原席位、重新发放空席密钥；更新不会将旧服务器的对局搬到新端口。
- 新安装默认使用 34936 大厅服务。已有服务器地址保留；连接 34935 时可点击“登录新版大厅”，用原账号重新登录 34936。
- 房间名称随开局进入记录和回放；运行器按服务端截止时间等待，支持新局默认 10 分钟行动窗口。

安装包仍为纯远程客户端，不包含服务器、游戏引擎或凭据。发布流水线对 Windows x64、macOS Intel、macOS Apple Silicon 分别构建主客户端和 Player，完成真实打包应用的模拟 API 验收与文件边界检查后才发布。

macOS 自动化构建与测试不等同于在用户真实电脑上完成 DMG 安装、Gatekeeper 和钥匙串手工验收。
