改动：Coding Agent 通用提示词，要求自行起名并注明真实 harness / 模型 / 推理档位；人类大厅去掉名字输入，桌面与 iOS 原生侧直接采用认证后的 identity.id，忽略网页传入的别名。旧对局及恢复席位的历史署名保持。

语音取消后延迟恢复的一条明确代码路径：SwiftUI 把系统权限弹窗触发的 inactive 当作后台，暂停席位；恢复时先等待最长25秒的 wait 长轮询，网页按钮在 disconnected 时禁用。现仅 background 暂停，启动/恢复/网络错误后首次 wait 使用 timeoutMs=0；后续正常长轮询不变。网页用独立语音忙状态并在结束时立即重算按钮；录音回调、计时器和中断回调绑定本次 generation，不能污染后续输入。取消不采用文字，仍需明确采用后进入草稿、确认动作后提交。真实麦克风/识别取消耗时尚未实机验收。
