# Coop Bench 0.9.6

人类花火操作改为点牌：点击自己的牌选择“出 / 弃”，点击队友的牌选择“颜色 / 数字”，查看高亮后确认。提示会高亮目标玩家所有匹配的牌；确认前可以取消或换牌。

- 显示持续保存的动作历史，以及每位牌主收到提示后知道的颜色与数字范围。
- 提示数量改为实心 / 空心圆点，整理牌面、提示知识和操作区的布局。
- 颜色提示只出现颜色，数字提示只出现数字；牌位统一从第 1 张开始显示。
- 决策回放用于查看模型 reasoning 与动作；独立的输入审计用于查看服务器保存的原始观测和运行器上传的实际模型请求，排查漏发信息。需要支持该接口的新版服务端；原始记录不存在时明确显示缺失。
- 房主与授权观战者可查看进行中对局的输入记录；玩家仍只持有本席信息。服务器原始观测隐藏行动凭证，不代表每次网络送达证明。
- 普通操作提示 4 秒后自动消失，可立即关闭，切换页面会清除旧提示。

发布流程要求 Windows x64、macOS Intel、macOS Apple Silicon 的管理端与 Player 原生包全部通过模拟 API 验收和安装包内容边界检查。模拟测试不代表真实模型实局或 Mac 实机安装验证。本版本为桌面客户端发布。
