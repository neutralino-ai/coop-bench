# 0.6.0：以玩家为中心的一屏回放

2026-09-18。用户要求回访一局时，不用滚动整页就能看见每个玩家的手牌、可见信息、思考和行动，减少 ID 等技术信息。此次更新针对随 Electron 分发的客户端界面。

## 界面

- 默认按玩家并排展示；上方为当前公共棋盘，下方固定时间线。当前行动者用绿色边框标出。
- 手牌和可见信息默认取本动作之前的记录。花火同时展示人类审计可见的牌面与该玩家自己的提示知识；这两者明确分开。
- 行动者显示本次决策。其他玩家显示截至此刻最近一次行动的简述，并标出该步编号，可直接跳转。不要把它理解成所有人此刻都在思考。
- 决策正文为 16px，动作 17px；长原文点击「完整输入 / 思考 / 消息」查看。短摘要没有被重新生成、改写成 reasoning。
- 对局选择、建局、整局消息、附件、导出、原始 JSON、技术标识和审阅笔记移到独立面板。左右方向键可以逐步回放；输入框或对话框获得焦点时不劫持方向键。
- 三人布局实测 1280×800 与 1440×900，无整页滚动且动作完整可见。非常小的窗口及更多玩家需要响应式降级，未声称所有人数、所有分辨率都能一屏显示全部原文。

## 审计边界

`web/replay-model.js` 只处理服务端已经保存的历史投影；`web/replay-ui.js` 组织人工审计视图。两者不供玩家 API 使用。

1. 动作前手牌从上一帧的同一时点取得，行动者的输入优先使用该动作绑定的 `observed`。没有快照时标缺失，不用终局或后续抽牌倒填。
2. 花火的人类审计牌面只按同一时点、稳定 card ID 匹配其他座位可见记录；投影矛盾或找不到同一卡时保持未知。不按槽位去匹配新抽的牌。
3. 比赛消息只按玩家与动作的 `observationId` 精确关联；不会按时间相近、相邻请求去猜。旧消息没有关联字段时，仍可从「完整记录」分页查看，但不能伪称已经对应本动作。
4. 只展示上传的模型输出 reasoning/thinking 字段；推理摘要单独标注。加密字段、删减字段、用户输入里引用的 reasoning 和工具输出都不冒充模型思考。
5. 每位玩家的背景读取每轮最多 5 页，按 3.1 秒间隔排队；单席缓存上限 2,000 条或约 8 MiB 字符，更多数据用原始消息分页查看。切换对局或退出时丢弃旧异步响应、关闭原文窗口并清空缓存。
6. API 原始槽位索引从 0 开始；界面手牌位置从 1 开始。模型原文保留其原来的数字和内容。

## 验证

- 自动测试 **294/294 通过**，新增 6 项历史视角、身份匹配、未来信息隔离、消息关联、推理来源与 Take Time 暗牌测试。
- Windows x64 的真实包内客户端：**31 项通过**，包含两种窗口尺寸、长思考原文展开、上传内容安全文本渲染，以及既有认证、密码、附件和隔离检查。
- Windows 包内单机兼容模式：**14 项通过**。
- 真实云端只读检查：用包内 renderer、preload 和 RemoteSession 打开已有花火 23/25 分轨迹，确认三人面板、原始决策简述、10 游戏目录和附件。全程仅 GET，没有写生产数据。
- 安装包内容白名单包含 21 个代码/静态文件；不包含生产凭证、数据库或实局数据。Windows 安装器仍未签名；安装向导未作为自动测试执行。

原始证据在忽略的 `artifacts/client-0.6.0-remote-smoke-final/`、`artifacts/client-0.6.0-local-smoke/`、`artifacts/replay-0.6.0-live-check/` 和 `artifacts/replay-all-tests.log`。CI/Mac 的本次结果以对应提交的 GitHub Actions 运行结果为准，不能用 0.5.0 的通过记录替代；真实 Mac 的 DMG、Keychain 手工验收仍见 [AGENTS.md](../AGENTS.md)。

## 交付与后端兼容

安装新版客户端即可得到新界面，仍连接原来的 HTTPS API。旧引擎 build 的轨迹可直接审阅；不会修改历史 build 或绕过确定性重放的版本检查。源码只给本地 HTTP 静态资源允许列表增加了回放文件，生产 API-only 部署未修改。

Windows 安装包：`release/Coop-Bench-0.6.0-win-x64.exe`。最终大小与 SHA-256 由 `scripts/verify-client-release.mjs` 写入被忽略的 `artifacts/client-release.json` 和 `release/SHA256SUMS.txt`。
