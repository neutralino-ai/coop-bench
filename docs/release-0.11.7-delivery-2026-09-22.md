# 0.11.7 自动刷新限流修复交付

包含[0.11.6候选的统一审计读取预算与恢复核验](release-0.11.6-delivery-2026-09-22.md)。0.11.6未公开Release，因附件验收时限未包含队列和Retry-After等待，取消未完成流水线。0.11.7只补齐该测试等待及确定性回归，应用仍遵守服务端额度，不增加重试写操作或改变后端。

确定性测试先耗尽初始额度，排队3次消息读取，再开始附件下载；首次下载在第14秒获得429，遵守5秒Retry-After后第19秒成功。因此原18秒验收窗口确实可能错误报失败，改为该项40秒，其他单项等待不变。新增测试同时校验响应字节。

最终候选/tag 为 `0588cfb7e31e3a515c686b986891ceb4bfdfe6c6`，正式流水线 [35704293255](https://github.com/neutralino-ai/coop-bench/actions/runs/35704293255)。本地117项单元测试、最终0.11.7 Windows打包应用126项合成API/UI验收通过，包含原始附件下载及原席位/模型上下文恢复。证据位于忽略目录 `artifacts/v0117-packaged`。实体设备未验收。

CI Windows最终包通过，但iOS模拟器发现既有登录导航竞态：列表先到、用户点回放后，游戏目录请求完成会调用home并取消回放。已用确定性单元测试在旧代码复现（实际home，预期replay）。流水线已取消，未公开Release；后续0.11.8修复该真实竞态，iOS夹具延迟目录请求以覆盖该顺序。保留原标签。
