# Coop Bench 0.10.0

账号拥有房间和人类席位。注册 token 只用于一次注册；以后使用用户名和密码登录。已有账号及密码继续有效。

- 大厅显示“我创建的”“我参与的”；创建者自动拥有房主权限，无需占席。换设备登录后可恢复自己的人类席位。
- 人类“返回大厅”保留原席位、手牌和记录；开局前可单独“释放席位”。
- 房主可在开局后复制原 seat token，凭证不会轮换；强制结束须确认，全部回放和原始消息保留。
- 内置 Agent 显示等待、请求模型、重连、失败和停止状态。失败后可重新测试模型并恢复原席位及本设备的持久上下文。
- Windows、Mac Intel、Mac Apple Silicon、iOS 使用统一版本；发布门槛包含 iOS 原生测试、iPhone 模拟器流程及未签名真机编译，Release 附同版本 Xcode 工程包。

iOS 继续使用自己的 Mac / Xcode 自签安装。工程包不是签名 IPA 或 TestFlight；模拟器验收不代表实体 iPhone 安装验证。内置 Agent 在客户端运行，iOS 须保持前台；服务器计时不因暂时离开而暂停。

此版本需要配套账号后端。开发候选构建不表示正式发布；以 GitHub Release 和服务器部署记录为准。0.10.0 前的席位没有账号归属，首次需持原 seat token 重新入席绑定；历史上仅存摘要且未重新提交过的旧凭证无法反向恢复，不会为复制而替换旧凭证。
