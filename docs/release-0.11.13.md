# Coop Bench 0.11.13

- 管理员对局清单显示规则分数、参赛人数与成员姓名、状态和结束原因；批量中止或永久删除前再次列出所选对局，供核对。进行中及中止未结算的分数明确标记，不把中止当作规则失败。
