# Coop Bench 0.11.3

进行中的回放在最新位置显示当前局面、高亮服务端正在等待行动的玩家，并按服务器截止时间显示倒计时。例如 p2 已做完、等待 p3 时高亮 p3。查看历史步骤时仍显示所选动作执行前的手牌与信息，高亮该步行动者；历史步骤和已结束对局不显示实时倒计时。倒计时到零后等待服务器更新，不在客户端猜测或执行动作。

内置 Agent 的完整轨迹占用原理由区和底部动作区的合并空间，理由和已确认动作保留在彩色轨迹卡内。移除“跳到这一步”链接，压缩手牌、本人提示和可见信息的标题区，保留原始视角及服务器签发记录入口。人类理由可在剩余空间内滚动阅读。

连接绿灯合并到顶部菜单，点击可强制检查连接；底部改为单行播放按钮和带步号的可拖动长时间轴，移除动作描述行。游戏标题和场景信息并排，公开交流入口合并到棋盘栏。同一1280×800窗口，Agent区由最初约168px提高至391px，未缩小正文。

包含 0.11.2 的 iPhone 开局 HTTP 400 修复。桌面三平台与 iOS 使用统一版本，macOS 签名、公证，iOS 通过 TestFlight 分发。模拟器验收不等于用户实体设备验收；不修改后端或中断对局。

兼容新的 default-action-v2 超时策略：客户端显示服务端给出的默认动作与状态，内置和外部 Agent 提示词不再写死旧的满提示规则。策略是否启用以服务端和本局记录为准。
