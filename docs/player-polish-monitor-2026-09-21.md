两个审计用途明确分开：“决策回放”检查模型当时的 reasoning、决策和动作；“输入审计”排查服务器漏发、错发以及运行器转交时的信息缺失。房主开局页分别提供入口，回放页工具栏只有一个“输入审计”入口，内部可按相同席位切换两个来源。

“服务器原始观测”来自后端持久保存的 observation，不从 state 拼装，不从模型 messages 提取。可切换席位、翻页、手动刷新或打开每 5 秒刷新。仅隐藏 decisionToken，JSON 格式化展示。“签发”不代表每次 HTTP 发送成功或模型已读取；没有记录不会补造。

“实际模型请求”只读 model-input，不混入模型返回的 reasoning / output / 独立工具记录；原始请求自身的历史、工具声明等完整保留。首次定位最新输入，如果是分片则从该请求首片开始；可从头分页读取历史，每 5 秒继续读取新增输入，不要求先提交动作。内存显示上限 100 条 / 2 MiB，服务器不删除记录。分片保留原貌，不冒充完整请求。切换席位、对局、登出、关闭窗口会取消旧请求并清除旧显示。配套后端开放授权 auditor 对进行中局面、观测、messages 的只读访问，玩家凭证仍不能跨席读取。

客户端自动测试 97 项通过；Windows Player 包内 16 项通过，截图与报告在 artifacts/live-message-final-player。输入审计主客户端包内 99 项通过，最终 build 9972d43017f8，包及报告在 artifacts/input-audit-main-final-package、artifacts/input-audit-verified-main。使用合成 HTTP fixture，不代表真实模型读取验证。Mac / iOS 本次未验证。原始观测监测、输入筛选及观战新权限需要部署配套后端和代理白名单；本次未部署或发布客户端。
