# Coop Bench 0.7.0

新增应用更新、可直接打开的规则面板与花火提示计数，改进密码输入和认证报错。保留三人一屏回放。

## 安装与更新

首次从旧版本升级，请在本 Release 下载匹配系统的安装器：

- Windows x64：`Coop-Bench-0.7.0-win-x64.exe`
- Mac Apple Silicon：`Coop-Bench-0.7.0-mac-arm64.dmg`
- Mac Intel：`Coop-Bench-0.7.0-mac-x64.dmg`

安装 0.7.0 后，打开“设置 → 检查更新 → 下载更新 → 打开安装程序”。Mac 下载 DMG 后仍需按系统提示将应用替换到应用目录；Windows 使用安装向导。旧版本没有检查更新按钮，需要手动安装本次更新。

公开仓库为 [neutralino-ai/coop-bench](https://github.com/neutralino-ai/coop-bench)。更新读取公开 GitHub Releases，按运行平台和架构选择安装包，不读取或发送游戏 API 凭证。固定仓库、HTTPS、有限重定向、大小上限、超时和 SHA-256 双重校验覆盖检查、下载和打开安装器的过程。未经校验的文件不会打开。

版本 tag 对应的 Windows x64、Mac Intel、Mac Apple Silicon 构建及包内验收全部成功后，CI 才会发布安装包。GitHub 的文件摘要与附带的 `SHA256SUMS.txt` 用于核对完整性，不能替代系统代码签名。当前 Windows 安装器未签名，Mac 未签名、公证；真实 Mac 的安装向导与系统安全提示仍需用户验收。

## 界面变化

- 顶部“游戏规则”：切换已加载的 10 款游戏，阅读规则概要、可用场景、实现范围和规则来源；当前历史对局优先使用它保存的规则元数据。花火新增中文版核心规则速查。
- 花火公共棋盘显示“剩余提示 x / 8”和 8 个标记。提示全队共享，提示消耗 1，弃牌或成功打出 5 恢复 1，最多 8；0 枚不能提示，8 枚不能弃牌。显示值随所选历史时点变化，默认行动前。原后端已有这些规则，本次没有更改引擎。
- 密码可临时显示，提示 Caps Lock、首尾空格和全角字符。保存、提交、关闭设置和退出时清空并重新隐藏输入；密码保持原始字符，不自动裁剪或归一化。
- 登录错误区分服务器认证拒绝与 DNS / TLS / 端口 / 网络失败。提示用户核对账号、服务器与输入，不把所有错误归因于密码。

花火规则以 [Cocktail Games 2019 规则](https://www.cocktailgames.com/wp-content/uploads/2016/03/Hanabi_regles_0519_BD.pdf)为当前实现依据，使用允许空提示的五色基础版本。实现未覆盖全部扩展。

## 登录排查的边界

这次检查确认受影响账户已保存密码、账户未停用且绑定正确，失败登录到达服务器后收到认证拒绝。没有取得用户密码，也没有证明具体输入差异；不能宣称根因已修复。没有重置生产密码或修改生产认证规则。

隔离的测试账号已通过设置密码、退出、错误密码拒绝、原样密码重新登录。测试密码含中文、全角字符和首尾空格，覆盖输入在界面、IPC 与服务端之间的精确保留。这些测试不等于替用户成功登录其真实账号。
