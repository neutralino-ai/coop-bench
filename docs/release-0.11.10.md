# Coop Bench 0.11.10

- 席位提示词改为 Coding Agent 通用入口，支持 Codex、Claude Code、GPT、DeepSeek 等 harness；要求 Agent 自取名字，并注明真实 harness、模型及推理档位。
- 创建房间时等待游戏目录加载完成，目录失败时可重试，避免快速操作时必填下拉框为空。
- 从大厅加入的人类玩家直接使用已登录用户名，不再填写玩家名字。
- 手机牌桌压缩牌面、提示、烟花堆及理由输入区，历史默认折叠。顶部固定显示行动者和倒计时，自己的回合使用蓝色背景。
- iOS 系统权限弹窗的短暂非活动状态不再暂停席位；恢复前台或重连时立即获取最新局面，避免等待长轮询。语音取消立即恢复网页按钮状态，旧识别回调不能写入下一次输入。
- 进行中回放默认自动跟随最新动作；拖动或翻页可查看历史，一键“回到直播”恢复跟随。直播更新独立于大厅筛选开关，牌局刷新不再等待完整轨迹加载。

桌面与 iOS 统一版本；Release 包含同版 Xcode 工程，iOS 使用既有签名身份上传 TestFlight。仅更新客户端，不部署后端或中断对局。实体设备麦克风与安装体验仍需实机验收。
