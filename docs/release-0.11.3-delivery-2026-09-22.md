# 0.11.3 交付记录

发布提交 `9b556f60e9994c8ce39049faf75033298d9bb4c2`，main 与 v0.11.3 相同，工作分支 `codex/ios-game-entry-fix`。用户已明确授权 Release 与 TestFlight。

手机 0.11.0 (20.1) 房主开局后 HTTP400：Swift SeatRuntime 读取消息时错误使用观察接口上限 500，实际消息接口最大100。改为100并保留分页恢复；合成接口同步严格校验分页，205条历史、空流、恢复游标、席位隔离及私有真实 PostgreSQL 回归通过。

回放最新位置以服务端 control.required 高亮待行动玩家，p2 已做完而等待 p3 时显示 p3；历史位置及结束局按选中动作高亮。最新位置显示服务端期限倒计时，使用 HTTP Date 校正；历史无实时计时器。真实 PostgreSQL 回归验证 p2 最新动作与 p3 待行动的区别。

连接灯合入菜单并支持点击强制检查，时间轴压成单行，播放与左右按钮在最左，数字轨道支持拖动；移除重复动作描述和“跳到这一步”。手牌、提示与原始视角入口合并排列，公开交流通过棋盘入口查看。Agent 轨迹复用原行动栏空间，1280×800下可用高度391px，1440×900下491px，正文不缩小。人类行动理由可滚动。

客户端识别 default-action-v2，并提示以服务端 control.timeoutAction 为准。超时策略来自服务端，不由客户端猜测或执行。用户已撤回“Agent 卡死”的判断；没有基于该现象改动重试状态机。现有网络故障验收主动丢失一次已接受动作的响应，并核验相同幂等键及相同动作重试。

本地107项单元测试、Windows实际安装包125项验收通过，截图检查无页面/时间轴溢出。中间候选四平台 CI 35695323579 全通过但未签名发布。最终正式签名/公证、iOS与TestFlight及公开发布流水线：[35696757070](https://github.com/neutralino-ai/coop-bench/actions/runs/35696757070)，用户追加紧凑轨迹卡要求后主动取消，结论 cancelled；未公开 Release，也未完成 TestFlight 上传。全部修改合并到 0.11.4 统一发布。
