# Coop Bench 0.11.2

修复 iPhone 在房主开局后进入牌桌时显示 HTTP 400 / INVALID_REQUEST、反复重连的问题。原生玩家在初始化本席轨迹时错误请求每页 500 条，而消息接口最多支持 100 条；现按每页 100 条读取并继续翻页到完整历史，再进入牌桌。人类玩家与手机内置 Agent 共用此修复。

模拟 API 现在校验真实消息分页上限，避免把非法请求当作成功。新增测试覆盖旧请求拒绝、空历史、205 条历史分页、恢复游标及席位隔离。隔离真实 PostgreSQL 验证旧请求返回 400 / INVALID_REQUEST，修复后返回 200，历史分页为 100 / 100 / 5，随后 rules 和 wait 均为 200。

桌面与 iOS 统一版本；正式发布依赖 Windows、macOS Intel / Apple Silicon 和 iOS 原生/模拟器验收，以及 Apple 签名、公证和 TestFlight 上传。工程 ZIP 不等于已安装的 iPhone 应用。用户设备上的安装后验收仍需实际完成。

本次不修改服务器、账号、房间或历史记录。
