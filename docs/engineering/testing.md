# 验证标准

| 改动 | 必须提供的证据 |
|---|---|
| 所有源码/工具变更 | 仓库规则、零错误零警告 lint、已纳入范围的严格类型检查、相关行为回归 |
| 协议/运行器 | 拒绝路径、隐藏信息、分页/去重、超时/重试、恢复与真实轨迹不泄露 |
| 共享网页/IPC | 桌面真实包模拟 API 验收；iPhone 窄屏/横屏和原生桥接验收 |
| 构建/依赖/发布 | frozen-lockfile、生产依赖安全审计、干净来源、制品边界、真实启动路径 |
| 文档/需求 | 有效链接、PRD 状态与验收/证据一致；不为文字修订重跑游戏 |

pnpm check 是共同入口；Client quality 提供快速检查，Remote clients 继续负责 Windows、两种 Mac 和 iOS 模拟器/原生编译。

当前严格类型入口为 client/protocol.mjs 和 scripts/release-source.mjs；其余 JavaScript 的完整迁移见质量债清单。lint 覆盖自有生产脚本和测试，第三方 vendor 不做风格重写。no-control-regex 因凭据/文件名的控制字符校验保留；no-unused-vars 是已记录的后续债，不能据此宣称所有推荐规则启用。

测试优先验证用户观察到的结果与持久状态，不只检查方法被调用。只 mock 外部非确定性边界；每个测试独占临时目录、端口和数据库 schema，并在失败时清理。不能在真实局、真实账号或生产数据库上运行破坏性验证。

新增门禁要有负例：本次 release-source 测试实际创建 Git 仓库，确认未提交、暂存、漏加文件与打包期间换提交均被拒绝，忽略的本地证据允许存在。没有执行的检查写未验收，跳过写原因。
