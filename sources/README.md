# Source references

The JSON files in this directory contain our source URLs, verification metadata,
and small structured inputs used during game implementation. Official rulebook
URLs also live in each adapter's `metadata.sources` and the game documentation.

Downloaded publisher PDFs, photographs, image crops, archives, HTML pages and
extracted full rulebook text are research caches. They are intentionally excluded
from Git and are not needed to install, test, build or run Coop Bench. A fresh
clone must not depend on those files. Local relative links in historical research
notes can therefore be absent; use the accompanying publisher URL.

Including source links is not a claim to redistribute the publisher's assets.
